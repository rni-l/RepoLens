本地优先 · 个人代码项目目录

把散落的代码项目收进一个清晰目录

RepoLens 是 macOS 本地桌面应用。它不替代 Git，只负责可靠扫描你配置的目录、识别代码项目、保留人工备注，并把项目快速打开到 Folder、Terminal、iTerm2、VS Code 或 Cursor。

首版核心

解决“我本地到底有哪些项目”的日常问题

只扫描你指定的根目录

用户显式配置多个扫描根，并可单独启用或停用；RepoLens 不会默认扫描整台电脑。

严格标记识别项目根

通过 package.json、pyproject.toml、vite.config.ts 等明确标记识别项目，避免把依赖或构建目录误收进库。

一行打开常用工具

项目列表直接提供 Folder、Terminal、iTerm2、VS Code、Cursor 操作；不可用工具会禁用，而不是让用户试错。

扫描不是黑盒

从扫描根到项目条目，每一步都可解释

首版重点是可靠本地索引。扫描失败、路径缺失、外部工具不可用都作为产品状态呈现，不把异常吞掉。

选择扫描根

通过原生文件夹选择器添加目录，例如 Documents、D/project 或特定工作区。

跳过依赖与构建目录

默认忽略 node_modules、dist、build、target、.venv、.next、.turbo 等高噪声目录。

保留用户维护字段

description、start_command、test_command 一旦由用户编辑，后续扫描不会覆盖。

首版边界

做成个人目录台账，不做另一个 Git 客户端

首版必须做

  • 扫描根配置、启用、停用与全量扫描。
  • 项目搜索、状态筛选、标签与技术栈过滤。
  • 项目详情、备注、命令、标签的编辑保存。
  • 缺失路径标记和扫描错误摘要。

首版明确不做

  • Git 操作管理、团队协作或云同步。
  • 自动 AI 总结替换人工描述。
  • 全源码理解或静默读取每个文件。
  • 复杂 monorepo 包级索引。

先把本地项目看清楚，再谈更智能的增强

这个原型聚焦 React/Vite/Tauri 首版 UI，可直接拆成 ProjectLibraryPage、ProjectDetailPage 和 ScanSettingsPage。
